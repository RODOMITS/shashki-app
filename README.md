# Шашки.App

Telegram Mini App для русских шашек. В главном меню видны имя и аватар из Telegram, две кнопки запуска и статистика. Матчмейкинг подбирает другого человека из очереди. В режиме тренировки можно выбрать цвет и один из трёх уровней бота.

## Запуск на BotHost

1. Создай Telegram-бота в [@BotFather](https://t.me/BotFather).
2. В BotHost создай проект с платформой **Telegram** и языком **Node.js**. Укажи Git URL этого репозитория, ветку `main` и файл запуска `index.js`.
3. Вставь токен в поле **Bot Token** в панели BotHost. При создании проекта включи публичный HTTPS-домен и укажи порт **3000**. Приложение слушает `0.0.0.0` на порту из переменной `PORT`.
4. Запусти проект. По адресу `https://<домен>/health` должен открыться ответ `{"ok":true}`. Приложение берёт публичный адрес из `APP_URL`, `DOMAIN` или `WEBHOOK_URL`. Если нужный адрес отличается, задай `APP_URL` в панели, например `https://my-game.bothost.ru/`.
5. Открой чат с ботом и отправь `/start`. Бот добавляет кнопку WebApp в сообщение и в меню чата. Кнопку меню также можно настроить в BotFather командой `/setmenubutton`.

Приложению нужен **Node.js 22.13+**. Если стандартный шаблон BotHost использует более старую версию, включи «Использовать собственный Dockerfile». Включённый в репозиторий Dockerfile использует Node.js 24.

Для команд Telegram используется long polling. Если этот токен уже работает в другом процессе или с Telegram webhook, останови предыдущий экземпляр и отключи его Telegram webhook в рамках переключения на эту сборку. Домен приложения в BotHost служит для WebApp.

### Настройки

| Переменная | Для чего нужна |
| --- | --- |
| `BOT_TOKEN` | Токен бота. BotHost передаёт его из поля **Bot Token**. |
| `APP_URL` | Публичный HTTPS-адрес приложения. Можно указать вручную. |
| `PORT` | Внутренний HTTP-порт. По умолчанию 3000. |
| `DATA_DIR` | Папка SQLite. BotHost обычно задаёт `/app/data`. |
| `GROQ_API_KEY` | Ключ Groq для уровня «ИИ». Задаётся в переменных BotHost. |

### Уровень «ИИ»

Создай ключ на [странице Groq](https://console.groq.com/keys) и добавь его в переменные BotHost как `GROQ_API_KEY`. Обнови деплой из ветки `main`. Уровень «ИИ» появится в выборе сложности. Используется модель [`openai/gpt-oss-20b`](https://console.groq.com/docs/model/openai/gpt-oss-20b). На бесплатном тарифе действуют [квоты Groq](https://console.groq.com/docs/rate-limits).

Модель получает позицию, восемь последних ходов обеих сторон и свои прошлые реплики. Движок добавляет рекомендацию после поиска продолжений и тактические факты по ходам. Если есть немедленная победа, модель выбирает один из выигрышных ходов. Варианты с мгновенной потерей всех шашек исключаются, когда есть ход без этой угрозы. ИИ комментирует свой выбор по-русски от первого лица. Контекст сохраняется вместе с партией. При таймауте, исчерпании лимита или недопустимом выборе используется ход, который заранее рассчитал движок.

Каждая завершённая партия записывается в SQLite. Статистика показывает общий итог онлайн-партий и игр с ботом. Активную партию можно продолжить после повторного открытия Mini App. Очередь подбора сохраняет место, пока открыто приложение и идут запросы состояния. Для проверки матчмейкинга нужны два Telegram-аккаунта. Запускай один экземпляр приложения на одном томе SQLite.

## Локальная проверка

Установи Node.js 22.13 или новее, затем запусти:

```sh
npm test
```

Тесты запускают временный сервер и проверяют подпись Telegram, матчмейкинг, правила ходов, ответы бота и сохранение статистики после перезапуска. Для запуска с реальным ботом можно заполнить локальный `.env` по образцу `.env.example` и выполнить `node --env-file=.env index.js`. Полноценная игра в клиенте Telegram требует публичного HTTPS-домена.
